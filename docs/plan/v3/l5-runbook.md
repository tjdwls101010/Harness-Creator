### L5-10을 기계적으로 재는 법

인터뷰가 끝난 뒤 대상 레포에서:

```bash
cd ~/Coding/l5-dogfood && python3 - <<'PY'
import pathlib, re
for f in list(pathlib.Path(".").glob("CLAUDE.md")) + list(pathlib.Path(".claude").rglob("*.md")):
    t = re.sub(r"```.*?```", "", f.read_text(), flags=re.S)
    paras = [len(b.split()) for b in t.split("\n\n")
             if b.strip() and not b.strip().startswith(("#", "|", ">", "-", "*"))]
    if not paras: continue
    print(f"{str(f):42} n={len(paras):3}  max={max(paras):4}  >=110w: {sum(1 for p in paras if p>=110)}")
PY
```

**통과 기준: 110단어 이상 문단이 0.** 하나라도 나오면 그 문단을 직접 읽고, 논증이 붙어 있는지 gotcha가 길어서인지 판단하세요 — 후자는 통과입니다.

## 5. 추가 관찰 (v3에서 새로 생긴 질문)

인터뷰 중 훅을 하나라도 생성하게 되면, **`hooks-events.md`가 로드되는지** 봐주세요.

이유: `hooks.md`(5,339단어)는 항상 로드되고 `hooks-events.md`(3,777단어)는 "이벤트를 고른 뒤에만" 로드되도록 설계돼 있는데, **그 이음매가 실제로 값을 하는지 아무도 측정한 적이 없습니다.** 훅 작업마다 결국 둘 다 읽는다면 분할이 아무것도 사지 못하는 것이고, 두 파일을 합치거나 조회 스크립트를 다는 게 맞습니다.

- 훅을 만들었는데 `hooks-events.md`를 **안 열었다** → 이음매가 값을 한다
- 열었다 → 이음매가 값을 못 한다. 몇 번째 훅에서 열었는지 적어주세요
