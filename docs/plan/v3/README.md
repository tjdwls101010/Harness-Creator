## 착수 전 3줄 요약

1. **순서가 곧 의존성이다.** PR1의 교리가 PR2의 판별식이다. 뒤집으면 기준 없이 9,476단어를 자르게 된다.
2. **판별식은 재현 가능하고 안전하다** — 독립 에이전트 2개가 0.7%p 안에서 일치, 가드레일 앵커 6/6 생존, `silent-failure` claim 10/10 생존. 하지만 **회수량은 ~6%로 초안 추정의 절반**이었고, 그래서 T1b(셀 압축)가 판별식에 추가됐다.
3. **과잉 트림은 분량이 아니라 claim 손실로 판정한다.** 전 파일 claim A/B에서 critical 손실 0이 유일한 hard gate다. 검증은 **싼 것부터** — kind 분포 스크리닝 → claim별 grep → 남은 것만 판정 에이전트. 파일럿에서 grep이 전부 해결했다.
